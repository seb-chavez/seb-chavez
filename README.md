## Selected work

**ChimeCore ACH platform** · Chime
Built 0→1 inside Chime's proprietary processor and ledger. **900+ transactions per second**, **300M+ entries annually**, **9.5M members** migrated off Galileo. Certified ODFI/RDFI flows with partner banks, shipped name matching, disputes, debit authorization, and ACH risk controls, and cut deposit review queue errors **99%**. **3 USPTO patent applications filed.**

**Risk-tiered onboarding** · Orum
Rebuilt onboarding into two verification paths: a lightweight identity match for enterprise clients whose end users were already KYC'd, and full **CIP with ongoing monitoring** for everyone else. Ran the identity stack behind it, **Socure** for KYC and watchlist screening across **4M+ end users**, **Middesk** for KYB and beneficial ownership.

**JPMorgan Chase RTP integration** · Orum
Payment orchestration, verification, and error handling behind Orum's real-time payments MVP.

**Instant account verification** · Flannel
First hire. Identified MVP scope with the CEO and helped secure partnerships with **The Clearing House**, **JPMorgan Chase**, and major FIs.

**Compliance due-diligence automation** · Wells Fargo
